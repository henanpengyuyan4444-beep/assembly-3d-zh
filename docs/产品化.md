# 这个项目怎么变成一门生意

一句话：**它不是一个 3D 动画工具，而是"把你家说明书变成能点的版本"的加工服务 + 一个可以复用的引擎。**

## 卖的是什么

| 客户拿到 | 我们做的事 |
| --- | --- |
| 一个链接，手机打开就能一步步装 | 手册逐页数字化，写成装配数据 |
| 每一步旁边有原说明书那一页 | 手册页与步骤的映射 |
| 中文步骤、中文五金名、中文提示 | 本地化与术语校对 |
| 版本更新后还能对上 | 手册改版时同步步骤与页映射 |

客户不需要有 3D 团队，也不需要把图纸给我们。他们给的是**已经印在纸上的说明书**，这是他们本来就有、但没法交互的资产。

## 三种接单方式（按客户成熟度）

1. **只做原页对照**（半天一款）：手册页 + 步骤映射，3D 由现成产品族生成或直接用手册图。适合预算低、只要"能点开对照"的客户。
2. **做中文定制款**（1 到 2 天一款）：照 `src/data/demo-custom.ts` 录入零件与步骤，得到完整中文 3D 指南。适合有 BOM、有尺寸表的品牌。
3. **扫描起草 + 人工校**（2 到 4 小时一款，取决于手册质量）：`SCAN_LANG=zh` 跑视觉模型出草稿，人工只改尺寸与顺序。适合款式多、上新快的卖家。

## 定价的锚点

- 按款：单款 800 到 1500 元（20 步以内，含一次修改），批量 20 款另行报价。
- 按年：签年度维护，包含每月 N 款上新与手册改版同步。
- 别按"3D 模型"报价，按"手册数字化 + 售后减负"报价：客服少接一半"怎么装"的电话，这是客户能算清的账。

上面是报价假设，不是已验证的市场价格。第一单应当用一款真实手册验证：客户愿不愿意为"能点的说明书"付钱，比做多少功能都重要。

## 单款交付的固定动作

1. 收手册与成品尺寸表，确认版权归属（只能用客户自己的手册）。
2. 手册逐页导出图片，放进 `public/manual-pages/<slug>/`。
3. 录入或扫描出零件与步骤，跑 `npm run dev` 逐页检查：零件会不会穿模、步骤顺序对不对、五金数量对不对。
4. 手机竖屏过一遍，确认单手能操作。
5. 交付链接与一份"如何改文案"的说明，客户自己就能改下一步。

## 边界，先说清楚

- 尺寸按手册示意图与成品规格反推，不是工厂图纸；做安装指导够用，做开料不行。
- 五金孔位是示意，数量与顺序对得上，孔径孔距没标定。
- 不替代安全要求：两个人、墙固定、承重这些提示要保留。
- 手册版权归客户；本仓库里只有自己画的示例页。

## 现在这套代码离"能接单"还差什么

- IKEA 目录产品的步骤文案还是英文，中文只覆盖自定义产品与扫描产品。
- 扫描链路依赖 Together AI，国内要换国产 VLM 并做一次端到端验证。
- 还没有后台：客户手册、版本、订单目前靠文件与人工登记。
